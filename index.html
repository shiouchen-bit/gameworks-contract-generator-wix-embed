Game development contract builder

遊戲開發外包契約產生器

操作流程

  1. 先填甲方、乙方與乙方收款銀行；已有資料時再用資料庫匯入。
  2. 選契約類型、法律關係、服務模組、付款與稅務條件。
  3. 細修條款後，可另外產生 NDA 或勞務報酬單。
  4. 最後檢查缺漏、生成契約，再下載 Word / HTML / TXT / JSON。

簽約對象

甲乙方身分、聯絡方式與收款資料

甲方：委託方 / 發包方

乙方 / 受託方 / 外包方

乙方收款銀行

從郵件 / 通訊 / 書面資料 / 圖片擷取

可貼上 Email、通訊訊息、書面文字，或上傳 TXT / MD / EML / HTML / JSON / CSV 與圖片檔。系統會先擷取可辨識文字，再嘗試帶入甲方、乙方與銀行欄位。

「擷取並匯入」會依甲方、乙方標籤自動判斷；「以甲方匯入」會把未標示的名稱、統編、地址、電話、Email 優先帶入甲方；「以乙方匯入」則優先帶入乙方與收款資料。

甲方資料庫

先填完甲方欄位，再保存為常用資料；下次選取後按匯入即可帶回甲方欄位。

乙方資料庫

先填完乙方與收款銀行，再保存為常用資料；匯入時會一併帶入銀行欄位。

當事人資料庫備份

匯出與匯入只支援本工具產生的 JSON 檔（.json），內容包含目前瀏覽器內的甲方、乙方資料庫，不包含契約案件草稿。

匯出時會優先詢問儲存位置，可放在個人電腦或個人雲端同步資料夾；若 Wix 或瀏覽器阻擋，會改開安全匯出頁或下載到預設下載資料夾。資料不會共用給其他使用者。

NDA 使用說明

NDA 用在正式契約前、報價提案、原始檔或商業資料揭露前。請先完成甲方與乙方資料，再選擇揭露方向、保密期間與返還或銷毀期限。

本草案採遊戲與軟體開發常見保密範圍：企劃、原始碼、美術音訊素材、技術文件、帳號權限、營運數據、玩家資料、商業條件與第三方授權資訊。正式簽署前仍應依實際交易與律師意見調整。
